  SMM Global Steel Trade Intelligence — How to open

【第一次使用 · First time】

1. 把收到的压缩包整包解压（右键 → 解压 / Extract All）。
   把解压出来的整个文件夹放到固定位置，例如「桌面 / SMM钢材平台」。
   ⚠️ 一定要保留整个文件夹，不要单独把某个网页拷出来——
      否则数据和图表会打不开。

2. 打开文件夹，双击  index.html （或 flagship.html）。
   会用默认浏览器打开（推荐 Chrome / Edge / Safari）。

3. 建议把它加入浏览器收藏夹，下次直接点开。

--------------------------------------------------------------

【怎么确认我看的是最新数据 · Check you're on the latest】

每一页的左下角都有一个小标签，例如：
       🗓 2010–2026.06 · build 2026-07-29
  - 前面是数据覆盖区间，后面 build 是这份文件的生成日期。
  收到新版本时，对一下 build 日期是不是比手里的新即可。

--------------------------------------------------------------

【收到更新版怎么办 · When you get an update】

1. 删掉旧文件夹（或直接覆盖）。
2. 解压新的压缩包到同一位置。
3. 刷新浏览器（Ctrl/Cmd + Shift + R 强制刷新）即可。

--------------------------------------------------------------

【中英文切换 · Language】
  右上角的「中文 / EN」按钮可一键切换整站语言。

【看不到图表？· Charts not showing?】
  多半是文件夹被拆散了。请重新完整解压整个文件夹再打开。
